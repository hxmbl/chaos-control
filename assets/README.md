# Bundled assets

Everything here is compiled into the binary by `crates/ui/src/assets.rs`.

| Path | What | Licence |
| --- | --- | --- |
| `fonts/PlusJakartaSans-*.ttf` | [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) Regular, Medium, SemiBold, Bold | SIL Open Font License 1.1, see `fonts/OFL.txt` |
| `icons/phosphor/*.svg` | [Phosphor Icons](https://github.com/phosphor-icons/core), only the ones the UI uses | MIT, see `icons/phosphor/LICENSE` |
| `icons/brands/*.svg` | Brand marks via [Iconify](https://iconify.design): [Simple Icons](https://github.com/simple-icons/simple-icons) and [SVG Logos](https://github.com/gilbarbara/logos) (Devin) | CC0-1.0, see `icons/brands/NOTICE.md` |
| `icons/chaos-control.svg` | The Chaos Control mark, drawn for this project | Same as the repo |
| `app/*` | App icon, all generated by `app/make-icons.py` from the halving-mark geometry (`app-icon.svg`, 1024 PNG, `AppIcon.icns`, `app-icon.ico`, and `ChaosControl.icon`, the Icon Composer bundle for macOS 26 Liquid Glass; compiling it needs `actool` from Xcode 26+, which cargo-bundle doesn't run) and macOS menu bar template glyph (`trayTemplate.png`, `@2x`), made from the mark. `crates/app/Cargo.toml` points `[package.metadata.bundle]` (cargo-bundle) at the icons; `crates/app/src/dock.rs` sets the macOS dock icon at runtime from `app-icon-1024.png` (so an unbundled `cargo run` shows the mark too). The menu bar item (`crates/app/src/tray.rs`, the `@2x` glyph as a template item) is disabled for now and not compiled | Same as the repo |

To add a Phosphor icon, copy its SVG from `phosphor-icons/core/assets/<weight>/`,
then add it to `FILES` in `assets.rs` and to `IconName` in `icon.rs`. The
`every_icon_is_bundled` test catches a missing entry.
