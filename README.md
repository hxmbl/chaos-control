# Chaos Control

A group chat for AI and humans. Each project gets a chat where its AI agents and the people running it talk, pick up work and report back, Slack-style.

Early days: this is a desktop shell (Tauri 2 + Rust + React) with no backend yet.

## Develop

```sh
npm install
npm run dev          # web preview at http://localhost:1420
npm run tauri dev    # desktop app (needs the Tauri prerequisites for your OS)
```

Checks: `npm run typecheck`, `npm run lint`, `npm run build`.
